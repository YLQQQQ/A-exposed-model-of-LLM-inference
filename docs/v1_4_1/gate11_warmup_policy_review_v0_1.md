## 联合首批的 repeat、开销及质量政策

1. **统计单位与 repeat。**每 run 一个 measured request/phase、repeat1；重复由完整 block 承载，同 block 的 N1 三组和同条件 P0/P1 保留配对/共同波动。单 sync B 是来源分析单位，任何推断保留 request/block cluster；token/kernel/sync/warmup 均不扩 n。正式候选 **6 个完整 block**（原三组序及镜像，平衡先后序），仅是有界成本候选，不是已冻结次数或功效保证。最终 n 与有研究意义的**绝对精度**一起决定；接近0的对照不能用相对CV或“CI必须离0”追采。
2. **精度与成本依据。**新 P0-w3 Request 样本 SD 2.679～20.727ms；在尚未证明的独立/平稳近似下，n=6 的均值 SE 粗预算为 G32 1.094、G512 8.462、N0 3.226、Nm 8.348、N16 1.367ms，**不是 CI、误差上界或保证**。旧 P1-w1 的配对 Request 差 SD 为 16.142～90.377ms，A_api/A_wait 波动也不同，不能由较小的新 P0 SD 推定 profile A 或 N1 差值的精度。没有依据冻结“正式 n=3/6 已足够”或任意毫秒/百分比阈值。
3. **观测扰动。**旧首批 Request P1−P0 相对差 −18.109%～+101.142%，旧 profile×variant 描述性方向不一致；新批没有 profile，不能说明 w3 下该问题消失。保留 signed 配对差和同 pass 的 Nm−N0、N16−Nm；前者还含包装/分支，后者是干预总差，不是纯等待。新 P0-w3 的 N16−Nm Request 仍为 +9.953、−19.504、+10.329ms，不能据此宣称收益。P0 为性能主口径，P1 为**观测执行**中的 A/单 sync B 解释；不统一从 A 扣差，不截负值，不因大/负差择样，不把配对差全叫 Nsight 成本。数值接受政策须与有限 claim 的分辨率匹配，不能为了通过临设百分比。
4. **质量硬门已有依据。**身份/输入/实际token/配置、completion/clock/drain、必要成员/依赖/ownership/terminal、诊断影响范围及整数互斥守恒不变。可证明局部缺口才进 unattributed，有证据部分可记账；影响不明拒绝对应窗口/claim。机制需用的单 sync B 无效不能放行该机制；G1 不要求自然默认流完整 B。coverage 是裁剪调用证据覆盖，不是 request 可解释比例；旧100%与45窗 unknown=0不能冻结“未来必须全0/100%”。数值局部缺口/coverage/时间解释门仍须根据绝对分辨率确定；不改变 A/S/B 来达到阈值。
5. **边界与 allocation 限制。**首批 marker 观测延迟 0.9246～2.6230ms，trace/host 窗口长度差仍按各 clock 内长度比较，非跨 clock 校准或全局误差界。不能将相同的整数守恒当时间边界正确性证明，也不能凭本批发明一个全局 tolerance。N1 九 profile 各三次 opaque allocation、实际预算差异保留；P0 没有该物理观测，不能假定与 P1 或各 variant 相同。内部等待不拆、大小未知、hidden 只相对于那次 sync；D/Signature 禁用。

11/11 统计谬误检查覆盖：按条件/block/次序分层，不以聚合方向替代局部；不从内部事件制造重复或推广到平台总体；无按成功/极值/低unknown筛样、无结果导向补采或显著性测试；Pilot 的多路径政策选择公开保留。小样本/顺序混杂为限制，因果和“无差即等价”均不主张；生态、基率、逆因果等不适用项不新增分析任务。这里提出政策建议，不作论文结论。
